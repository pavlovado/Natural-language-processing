# 💬 Обработка текста с помощью методов NLP

В этом проекте показано, как можно применять методы обработки естественного языка (NLP) для анализа и классификации текстовых данных. Вся реализация представлена в Jupyter Notebook.

 **Файл блокнота:** `NLP.ipynb`  
[ Открыть в Google Colab](https://colab.research.google.com/drive/1ZtjtZHsztpEhbleEo3jDLRBByzzMLBRd?usp=sharing)

---

## 🚀 Что реализовано

-  Загрузка и предобработка текстовых данных
-  Токенизация, очистка, удаление стоп-слов
-  Обучение модели для классификации текста (например, отзывов)
-  Отображение метрик обучения (accuracy, loss)
-  Оценка модели на тестовых данных
-  Примеры предсказания на новых текстах
